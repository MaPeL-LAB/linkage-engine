# Current Limitations

- The repository is a documentation-first pre-alpha scaffold.
- Target linkage commands are not implemented.
- No candidate generator, comparison engine, model adapter, calibrator, solver, or adjudication processor exists yet.
- Dependency ranges have not been resolved into a tested Python 3.12 constraints file.
- No licence has been selected.
- No performance target has been validated.
- No real-data, population, fairness, or operational validation has occurred.
- Multi-source resolution and PPRL are research tracks, not implemented features.
- The example configuration contains synthetic threshold values that are not operational recommendations.
- CI validates the scaffold and repository boundary only until later milestones are implemented.

These limitations are intentional. The repository must not claim capabilities before they are implemented and verified.
