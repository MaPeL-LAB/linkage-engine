# Research Source Provenance

The initial documentation set was derived from a user-supplied deep-research report dated **2026-08-16**, prepared specifically for `MaPeL-LAB/linkage-engine`.

The report established the repository as a greenfield private project and recommended a configuration-compiled, privacy-bounded pipeline using DuckDB, Splink, XGBoost, optional LightGBM/PyTorch, OR-Tools, SciPy, NetworkX, strict Pydantic configuration, synthetic-only repository data, explicit no-match assignment, and leakage-resistant validation.

The repository documents preserve that framing while:

- converting transient report citation markers into stable BibTeX keys;
- separating established evidence from architectural decisions;
- adding an explicit alternative-software comparison;
- documenting PPRL as a deferred research track rather than an MVP claim;
- recording unresolved questions instead of silently filling evidence gaps.

The canonical bibliography is `docs/references/references.bib`. Markdown citations use bracketed keys such as `[@fellegi1969theory]`.
