# Security Policy

Do not disclose security or privacy vulnerabilities in a public issue, discussion, pull request, or commit message. Use GitHub private vulnerability reporting when enabled, or an approved private MaPeL-LAB channel.

High-priority issues include configuration-driven execution, path traversal, unintended DuckDB filesystem/network access, value leakage in logs/errors, output-whitelist bypass, unsafe model deserialisation, weak-label promotion, row-level CI artifacts, and workflow-permission weaknesses.

The project is pre-alpha; only the current default branch is under active development.
